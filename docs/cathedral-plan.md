# 우주 대성당 구현 기준

작성: 2026-10-07. 근거: 사용자가 승인한 대화 계획, spec.md, designs.md,
AI_IMPLEMENTATION_DOC_STANDARD.md, AI_CODING_STANDARD.md, 현재 curses 구현.

## 목표와 동결 결정
120×40의 문자 대성당, 플레이 중심의 장관. 80×30 축약/64×28 최소 지원.
Python 표준 라이브러리/curses, 게임 규칙·리플레이·저장 version1 유지.
기존 저장된 테마 선택은 보존하고 새 저장의 기본은 cathedral.
기존 18 배경/25 효과는 갤러리에서 계속 선택한다.
청록/보라/금빛과 흑청색 여백, 중앙 제단·장미창·아치·천체 고리.
새 테마의 보드 빈칸은 정적이며 리본/무지개/동시 폭발을 사용하지 않는다.

## 내부 계약
- RenderContext: width/height, 보호 직사각형들, ASCII/Braille, quality.
- ArtCanvas: 셀별 glyph/style/depth, 2×4 Braille 점 마스크, 선/곡선,
  보호 영역 및 경계 클리핑. 가까운 깊이가 우선. ASCII/비Braille 폴백.
- ArtDirector: trigger(name,data,now), 상태 조회. 주 연출 하나, 국소 연출 유한 큐.
  결과(5)>올클리어(4)>Tetris/T-spin(3)>level(2)>clear(1).
  동일/낮은 우선순위는 강도만 병합하고 기존 종료 시간을 연장하지 않는다.
- CathedralScene: 위 계약으로 장면을 생성하며 엔진에 쓰지 않는다.
- Palette: curses 지원 범위 내 고정 색상쌍. 256색→8색→모노 폴백.

## 기법과 타이밍
Braille 연속 곡선/원근 투영/깊이 판정/문자 음영/반블록 전경·배경/
디더링/시간 감쇠 잔상/극좌표 장미창/입자 조립 타이포그래피.
회전·홀드 0.22초, drop 0.35초, clear 0.55초, Tetris/T-spin 1.2초,
올클리어 1.8초, level 0.9초, 결과 1.8초. 게임 입력/시간 중단 없음.
배경→환경/국소효과→보드/ghost→HUD→모달, 보호 영역은 배경부터 마스킹.
flash=false이면 밝기 펄스 제거, shake=false이면 위치 고정, braille=false는
점 문자 제외. F 토글과 기존 fx_speed/intensity/density 존중.

## 구현 순서
1. 문서와 회귀/계약 테스트(실패 확인).
2. 캔버스/팔레트/장면/연출 시간축.
3. 기존 UI/저장/번역/갤러리 연결.
4. 고정 프레임 컬러 캡처, 연속 프레임, PTY, 성능, 전체 회귀 및 문서 동기화.

## 완료 기준
실제 블록/ghost/HUD 보호, 고정 시간 결정성, 우선순위/수명/상한,
ASCII/모노/8색/256색/작은 창, 저장 호환, 게임 체크섬 불변.
120×40 렌더링 p95 16.7ms 목표. 평균/p95/max와 PTY 출력량 구분 기록.
부하 시 배경 갱신률→곡선 샘플→잔상 축소. 시각 검토는 컬러 프레임과
연속 프레임으로 수행하고 실제 사용자 터미널/폰트 차이는 잔여 제한으로 기록.

## 구현 중 구체화
- 기존 설정을 보존하면서 새 아트를 바로 실행할 수 있도록 `--theme cathedral`을
  추가한다. CLI 테마는 해당 실행에만 적용하고 종료 시 기존 저장값으로 복원한다.
- 절차적 레이어의 갱신 위상을 분산하고 건축선은 캐시한다. 합성 결과는 고정 시각에
  결정적이다. 캡처 HTML은 런타임 출력의 셀/색을 보존하며 외부 서비스 없이 재생한다.
