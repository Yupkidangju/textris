# 음악 감상 모음 선택 개선

작성: 2026-10-08. 근거: 사용자 후속 요청, 현재 `expansion_ui.py`, 오디오 카탈로그,
`spec.md`, `designs.md`, AI 구현 문서·코딩 표준. 미확정 요구 없음.

## 목표와 범위

현재 테마만 보이고 Tab 필터로 전통곡을 찾아야 하는 진입 화면을 개선한다.
Extras → Soundtrack 진입 시 모음을 선택하고 그 모음의 곡 목록을 연다.
음원·재생 엔진·게임 셔플·저장 스키마는 변경하지 않는다.

## 동결 계약

- 모음 순서: Traditional Tetris(8), Cosmic cathedral(3), Cyberpunk(3), Space(3),
  Fire(3), Retro CRT(3), Monochrome(3), All tracks(26). 이름은 기존 테마 번역을 사용한다.
- 최초 커서는 전통곡 모음. 방향키/W/S 선택, Enter로 열기, Esc/Q는 Extras 복귀.
- 곡 목록의 재생목록은 선택한 모음에 한정한다. 모든 테마를 게임 테마 변경 없이 감상한다.
- 목록에서 Esc/Q/Tab은 현재 감상을 종료하고 모음 선택으로 복귀하며 모음 커서를 유지한다.
  새 모음에 들어가면 곡 커서·스크롤을 초기화한다. 기존 재생/탐색/셔플/반복/음량 키는 유지한다.
- 모음별 곡 수는 비동기 카탈로그에서 계산한다. 카탈로그 준비 전에도 모든 모음은 표시하고
  빈 목록에서 안전하게 대기한다. 감상으로 게임 세션·기록·리플레이를 만들지 않는다.
- 최소 64×28에서 8개 모음, 선택·열기·복귀 안내가 모두 보인다. ASCII/모노도 지원한다.

## 구현 순서와 검증

1. UI 회귀 검사로 전통곡 노출·6테마 선택·전체 목록·복귀를 먼저 고정한다.
2. 모음 선택 화면·입력·영문 문자열을 추가하고 README의 진입 방법을 동기화한다.
3. 전체 회귀 검사와 Windows 실제 콘솔 입력/화면/오디오 검사를 수행한다.
4. v1.2.1 패키징과 새 EXE 검증 후 커밋·태그 푸시 및 릴리스 workflow를 확인한다.

오디오 파일을 변경하지 않으므로 39분 전곡 재생 검사를 반복하지 않는다. 이번 검증은
모음 선택·목록 범위·실제 입력·짧은 재생·기존 감상 조작·자원 회수에 한정한다.
