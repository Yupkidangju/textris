# 영문 터미널 호환성과 전체 아트 업그레이드

작성: 2026-10-07. 근거: 최신 사용자 2개 요구 및 검증 후 태그 푸시/릴리스 요청,
현재 코드와 AGENTS/구현·코딩 표준. 기존 우주 대성당 구현을 공통 기반으로 확장한다.

## 범위와 판단
1. 제품 UI를 영문 ASCII 문자열 하나로 통일한다. 저장된 ko는 en으로 이행하고
   구형 --language ko 입력은 호환 수용하되 출력은 영어다. 설정 언어 선택 제거.
   Unicode 아트는 별도 문제다. ASCII 안전 출력 경로를 모든 화면과 최종 출력에
   보장하고 비UTF 인코딩/Windows 기본 환경에는 보수적 자동 폴백을 사용한다.
   Unicode 명시 선택은 UTF 지원 환경에서 제공한다. 모든 터미널/폰트 출력 보장을
   주장하지 않고 Linux 실제 PTY, Windows API/인코딩 모의 검증, CI로 경계를 기록한다.
2. 음원 재생기 부재/실패를 terminal bell로 대체하지 않는다. 조작/메뉴 입력에서도
   beep/BEL 출력이 없어야 한다. 재생 불가 상태는 영문 silent 안내로 표시한다.
3. 6개 테마 모두 보호 영역/서브셀/깊이/일관된 팔레트와 유한 이벤트 연출을 쓴다.
   cathedral=성당/장미창, cyberpunk=네온 도시/크롬 격자, space=천체/중력 궤도,
   fire=태양 코로나/상승 불꽃, crt=인광 벡터/회로, mono=판화/기하 간섭 문양.
   단순 색 교체가 아닌 서로 다른 구도를 구현한다.
4. 갤러리 19개 배경/25개 효과, 메뉴·쇼케이스·준비/결과·보스/분석 등 화면의
   텍스트 아트를 공통 품질로 올린다. 기존 저해상도 무지개/리본 경로를 실 UI에서 제거한다.
5. 검증 후 기존 CI와 태그 관례를 확인해 적절한 SemVer 릴리스 커밋/태그를
   푸시하고 원격 빌드/릴리스 상태와 자산을 검증한다. 사용자 2026-10-07 명시 승인.

## 인터페이스/구현 순서
- 공통 ArtCanvas/RenderContext/ArtDirector 유지. ThemeScene.render(context,t,theme,...)
  는 테마별 장면, GalleryArt.render(context,t,name,age=None,intensity=.75,density=.75,flash=True)
  는 전체 기존 카탈로그의 고해상도 장면/효과를 반환한다.
- Palette는 theme에 따라 색 단계 변경. UI 보호, 설정 토글, 게임 규칙/저장 기록/
  리플레이 계약 유지. 갤러리 이름·키 변경 없음.
- 문서→영문/출력 회귀→오디오 및 갤러리 독립 구현→공통 테마/UI 통합→검증→릴리스.
- 오디오 작업자는 audio.py와 서비스 테스트, 갤러리 작업자는 gallery_art.py와
  전용 테스트만 수정. 주 구현자는 나머지 UI/호환/테마/문서/통합을 담당한다.

## 완료 게이트
영문 제품 문자열 전부 ASCII; CP949/CP1252/ASCII/UTF-8 안전 경로;
키 입력·오디오 실패에서 beep/BEL 없음; 저장 ko→en 기록 보존;
6테마/44갤러리 항목 컬러 프레임 검토, Unicode/ASCII/모노/64×28..160×50;
합성 보호/캐시 결정성/수명/속도/입력·리플레이 불변;
전체 테스트/빌드/실제 PTY/성능(120×40 p95 16.7ms 목표, 전송 별도);
버전/README/CHANGELOG/spec/designs/검증 근거 동기화;
태그 원격 도달, CI 성공, 릴리스와 대상별 자산 확인.

## 측정 후 조정
첫 120×40 측정에서 모노 판화의 선분 재샘플링이 p95 39.66ms로 목표를 넘었다.
ArtCanvas 선분을 정수 서브셀 Bresenham으로 바꿔 중복 부동소수점 샘플을 줄인다.
보호/깊이/ASCII 계약과 연결된 끝점을 회귀 검증하고 최대 두 차례 재측정한다.
