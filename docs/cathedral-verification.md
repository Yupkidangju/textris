# 우주 대성당 구현 검증

작성: 2026-10-07. 근거: 승인된 `cathedral-plan.md`, 현재 소스,
실행한 unittest/PTY/렌더링 벤치마크 및 고정 이벤트 컬러 캡처.
환경: Linux, Python 3.14.4, curses, PTY TERM=xterm-256color.

## 변경과 결과

기본 테마 cathedral을 추가했다. 아치·장미창·천체 고리·깊이 있는 문자 조각·
반블록 광막과 이벤트별 연출을 별도 합성한다. 기본 게임 규칙은 변경하지 않았다.
기존 저장 테마는 유지하며 `python3 -m textris --theme cathedral`로 바로 실행한다.

게임 보드/블록/고스트/HUD는 보호 영역이다. 대형 연출은 하나로 제한하고,
회전/드롭 등 국소 연출 큐는 최대 8개다. 동일·낮은 우선순위가 주 연출 수명을
연장하지 않는다. ASCII/비Braille/모노/8색/256색 및 작은 화면을 검증했다.
모노에서도 위험 상황을 DANGER 문구로 전달한다. 제한된 색상쌍에서도 블록의
기본 색상 정체성을 유지하는 회귀 검증을 추가했다.

## 자동 검증

- `python3 -m unittest discover -v`: **96개 통과**, 42.605초.
- `python3 -m compileall -q textris tests`: 통과.
- 새 계약 검증: Braille 비트 좌표, 선/깊이/보호 영역, 색상쌍 한도,
  새 기본/기존 테마 저장 왕복, 이벤트 수명/우선순위/속도/섬광,
  고정 시각 캐시 결정성, 보드 정보 불변, 문자 폴백과 리사이즈.
- 기존 회귀: 게임 코어, 장기 시뮬레이션, FX on/off 체크섬,
  세션/리플레이/저장/보스/오디오 서비스/CLI와 실제 PTY 입력.
- 독립 읽기 전용 검토의 5개 지적을 재현 테스트로 고정한 뒤 수정했다:
  리플레이 전환 시 새 연출 초기화, 갤러리 F 토글, 성취 문구의 큐 소유권,
  바깥 캐시의 정규 시각, 제목과 대형 문자 아트의 수직 분리.
  검토의 경미 2건도 결정성/HUD 보호 계약에 해당해 같은 수정 단계에서 처리했다.

세부 실행 기록은 `.antigravity/archive/cathedral/`에 있다.

## 성능

`python3 -m tests.benchmark_cathedral` — 다른 테스트와 분리하여 측정.
120×40, 프로필별 360프레임, 테트리스/올 클리어 포함, 실제 App.draw 호출.
측정용 출력 스텁은 터미널 전송과 테스트용 문자 폭 assertion 비용을 제외한다.

| 품질 | 평균 | p95 | 최대 |
| --- | ---: | ---: | ---: |
| 전체 | 9.153ms | 15.069ms | 29.188ms |
| 적응형 .7 | 8.029ms | 14.052ms | 20.860ms |

p95 16.7ms 목표 충족. 최초 캐시 생성 등 개별 프레임은 16.7ms를 넘을 수 있으며,
터미널 전송까지 포함한 고정 60FPS 보장은 아니다. 런타임은 비용에 따라
갱신률·곡선 샘플·잔상을 단계적으로 조정한다.
원본 수치: [cathedral-performance.json](cathedral-performance.json).

별도 120×40 실제 PTY 쇼케이스 2.5초: 156,126바이트, 약 62,447바이트/초.
확장 색상 escape와 Braille UTF-8 존재, 종료 코드 0, traceback 없음,
ECHO/ICANON 복구 확인. 이는 출력량 측정이며 네트워크 터미널 지연 측정은 아니다.
[PTY 수치](cathedral-terminal.json), [마지막 문자 화면](cathedral-pty.txt).

## 확인 한계

- 사용자 물리 터미널/폰트에서 직접 보거나 플레이하지는 않았다. 실제 PTY와
  렌더러 캡처를 검증했으며, 폰트에 따라 Braille 모양/점 간격이 다를 수 있다.
- PNG 검토 도구는 설치된 Pillow·DejaVu 폰트를 사용했다. Braille은 해당 글리프를
  지원하는 DejaVu Sans로 그린다. HTML 생성과 게임 자체는 표준 라이브러리만 쓴다.
- Python 3.10 호환 문법을 사용하지만 이번 실행 검증은 3.14.4에서 수행했다.
- 오디오 합성/서비스 회귀는 통과했으며 실제 청취는 이번 미술 변경 검증 범위 밖이다.
- 기존 사용자 저장값은 보존했으므로 이전 테마가 저장되어 있으면 CLI 또는 설정에서
  우주 대성당을 선택해야 한다. 커밋·배포는 수행하지 않았다.
